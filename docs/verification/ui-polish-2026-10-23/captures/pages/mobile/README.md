# Brief 24's Pages On A Phone Held On Its Side, In The Order A Player Meets Them

The same 67 pages as `../README.md`, at the owner's word on 2026-10-23 ("the full page capture of each page on both pc
and mobile."), on the same build. They're seen as a phone shows them held on its side, 844 by 390, a touch screen with no
hover, at twice the pixels; upright, a phone shows only Rotate Your Phone To Play since brief 23. The menu is opened
through Menu and closed again before each page is taken.

Each page is captured at the window's own size, so it is set out for that window and never for a taller one: the bar
once, then what scrolls (the page, or a dialog's body) a window at a time, then the part below it (a dialog's foot),
joined.
Toasts were hidden while a page was taken, since one would repeat down every window. A page taller than 12,000 of the
image's pixels is in parts, each overlapping the one before it by 300, so nothing falls between them.

The script, `../../../../ui-2026-10-23/app/pages.mjs` (the same one), is kept, with `pages-compose.py` and this README's
generator, `pages-readme.py`, beside it; brief 22's were scratch copies. It opens each save as a player opens one, from
the saves with Continue, and reaches each page from the menu and each tab by pressing it, Calendar and Updates from
Home's Open Calendar and View All Updates, since brief 24 took both from the menu.
- **What it met:** 0 page errors, console errors or steps it couldn't take; 0 pages showing the rotate screen;
  0 pages wider than the window.
- **Its record:** `pages.json`, each page's files, its headings and the clock as the bar showed it.
- **In parts:** 4 pages.
