# Evidence The Coverage Matrix Cites

Files the editors read while building `docs/text/surfaces/*.json`. They were copied here from the session's scratch
folder, with each one's path kept below `b17/`, so each row's evidence can be opened from the repository. Before this,
those refs pointed at the scratch folder, which exists only in the session's container.

- `b17/walk-before/<width>/<save>.json`: every screen's text, in order, on the built app of `bbb82253` (brief 16 as
  merged), walked by `tools/text-walk.mjs` through the scenario saves at 1440 and 390 wide.
- `b17/before/<student>.json`: the brief-17 students' runs on `bbb82253` (`tools/voices.ts`), with what each was told,
  in order.
- `b17/money-walk/`, `b17/papers-work/`, `b17/e-school-scratch/`: each editor's after-walks, before-walks and notes, on
  its own branch before the merge.
